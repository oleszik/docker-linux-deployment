# Docker Linux Deployment

## Goal
Build a production-style example of deploying a small web application on Ubuntu with Docker Compose, showing the skills needed to deploy, diagnose and maintain real client applications.

## Planned features
- Python/FastAPI service
- Docker and Docker Compose
- PostgreSQL database
- Nginx reverse proxy
- Persistent volumes and environment configuration
- Health checks, restart policies and logging
- Backup/restore scripts
- HTTPS and troubleshooting documentation

## Portfolio objective
Demonstrate Docker, Docker Compose, Ubuntu/Linux, Nginx, networking, deployment, logging, troubleshooting and service integration.

## Status
Planning / initial development.
